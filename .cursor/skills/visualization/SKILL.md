# Visualization

Plots should be publication quality.

Always include

Title

Axis labels

Legend

Readable font sizes

Consistent figure sizes

Save figures instead of only displaying them.

Prefer PNG and PDF outputs.

When visualizing forecasting results include

Actual values

Predicted values

Forecast boundary

Validation region

If comparing models

display them on identical axes whenever practical.

Avoid cluttered figures.

Use colors consistently throughout the project.
